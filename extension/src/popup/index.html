          Create a passphrase
          
        
          
          A passphrase is the password for this vault. It unlocks your saved
          details locally and is never sent to Cyclops servers. Use something
          you can remember.
        
          
        
          
          Remembered values are encrypted on disk. The key is derived from this
          passphrase and kept only in memory — if you forget it, the data is
          gone, and that is the point.
        
          
        
        
        
          
          
        
          
      
          

      
      
          
        
          Unlock to use saved details
          
        
          
          Locked means Cyclops can see that a vault exists, but cannot read or
          use remembered values. Unlock only when you want saved details to be
          available for the current task.
        
          
        
          This vault is locked. Nothing can be read until it is opened.
